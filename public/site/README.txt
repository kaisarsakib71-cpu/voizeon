📁 ফাইল স্ট্রাকচার
------------------------------------------------------------
index.html        → হোমপেজ
artists.html      → সব ভয়েস আর্টিস্ট (সার্চ + ফিল্টার)
artist.html       → একজন আর্টিস্টের প্রোফাইল (artist.html?slug=tanvir-hasan)
demos.html        → ডেমো লাইব্রেরি (নিউজ / অ্যাডস / ডকুমেন্টারি ...)
upload.html       → আর্টিস্টদের ডেমো যোগ করার ফর্ম
contact.html      → যোগাযোগ ও কোট রিকোয়েস্ট
admin.html        → বুকিং রিকোয়েস্ট ও ডেমো ম্যানেজ
assets/css/style.css  → পুরো ডিজাইন (অলিভ + সবুজ থিম)
assets/js/data.js     → আর্টিস্ট ও ডেমোর তথ্য  ← এখানেই এডিট করবেন
assets/js/engine.js   → অডিও প্লেয়ার + স্টোরেজ
assets/js/app.js      → পেজের লজিক
assets/img/           → ছবি (hero-studio.jpg, booth.jpg)
assets/audio/         → এখানে আপনার আসল ভয়েস ফাইল রাখুন


🚀 InfinityFree-তে আপলোড করার নিয়ম
------------------------------------------------------------
১. InfinityFree কন্ট্রোল প্যানেল → "Online File Manager" খুলুন
   (অথবা FileZilla দিয়ে FTP-তে কানেক্ট করুন)
২. "htdocs" ফোল্ডারে ঢুকুন।
৩. ভেতরের ডিফল্ট ফাইল (default.php / index2.html) মুছে দিন।
৪. এই ফোল্ডারের সব ফাইল ও "assets" ফোল্ডারটি htdocs-এর ভেতরে আপলোড করুন।
   ⚠️ ফোল্ডারসহ আপলোড করুন — assets ফোল্ডারের গঠন যেন ঠিক থাকে।
৫. ব্রাউজারে আপনার ডোমেইন খুলুন — সাইট লাইভ! 🎉
   (নতুন ডোমেইনে DNS আপডেট হতে ৫–৭২ ঘণ্টা লাগতে পারে)


🎙️ আসল ভয়েস ডেমো যোগ করবেন যেভাবে (স্থায়ীভাবে)
------------------------------------------------------------
১. আপনার mp3 ফাইলটি  assets/audio/  ফোল্ডারে আপলোড করুন
   যেমন: assets/audio/tanvir-news.mp3
২. assets/js/data.js ফাইলটি খুলে সংশ্লিষ্ট ডেমোর লাইনে
   audioUrl: ""   →   audioUrl: "assets/audio/tanvir-news.mp3"
   লিখে সেভ করুন।
৩. ব্যস! এখন প্লে করলে আপনার আসল রেকর্ডিংটাই বাজবে।

নতুন ডেমো যোগ করতে data.js-এর DEMOS লিস্টে এভাবে একটি লাইন বসান:
  { id: 21, artistId: 1, title: "নতুন ডেমো", category: "news",
    language: "বাংলা", tone: "গম্ভীর", description: "বর্ণনা",
    durationSec: 30, audioUrl: "assets/audio/new-demo.mp3" },

নতুন আর্টিস্ট যোগ করতে ARTISTS লিস্টে একইভাবে একটি অবজেক্ট বসান
(slug অবশ্যই ইউনিক ইংরেজি হতে হবে, যেমন "rahul-ahmed")।

ক্যাটাগরির key গুলো: news, ads, documentary, drama, ivr,
audiobook, elearning, podcast


ℹ️ কিছু জরুরি কথা
------------------------------------------------------------
• যেসব ডেমোতে audioUrl খালি, সেগুলোর জন্য ব্রাউজার নিজেই একটি
  "নমুনা টোন" তৈরি করে বাজায় — যাতে প্লেয়ার সবসময় কাজ করে।
  আসল ফাইল দিলে ঐ টোনের বদলে আপনার রেকর্ডিং বাজবে।
• upload.html থেকে যোগ করা ডেমো ও contact ফর্মের রিকোয়েস্ট
  ভিজিটরের নিজের ব্রাউজারে জমা থাকে (IndexedDB)। সার্ভার নেই বলে
  এগুলো অন্য ডিভাইসে যায় না। তাই:
    – সবার জন্য দেখাতে চাইলে data.js-এ যোগ করুন (উপরের নিয়ম)
    – কোট রিকোয়েস্ট সাবমিট করলে "ইমেইলে পাঠান" লিংক দেখানো হয়
• ইমেইল ঠিকানা/ফোন বদলাতে: প্রতিটি html ফাইলে
  hello@dhwanistudio.bd এবং +8801700000000 খুঁজে বদলে দিন।
• রঙ বদলাতে: assets/css/style.css-এর একদম উপরে :root ব্লকে
  --olive-* ও --leaf-* ভ্যারিয়েবলগুলো পাল্টালেই পুরো সাইটের রঙ বদলাবে।
